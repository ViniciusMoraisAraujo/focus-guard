## Decisões importantes

- **Foco no Bloqueio Local Robusto**: O FocusGuard foca 100% no bloqueio local de alta integridade via `hosts` + Firewall (IPv4/IPv6), Clock Guard via NTP, Interceptor Page com CA local e proteção anti-burla, eliminando a complexidade de atuar como servidor DNS para a rede local.
