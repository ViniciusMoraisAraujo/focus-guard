# Sessão — 2026-08-28

> **Status:** 🟢 Refatoração do DNS Sinkhole em Clean Architecture e Clean Code concluída na branch `refactor/dns-sinkhole-wifi-clean-arch`, com automação de conexão DNS em adaptadores de rede (Wi-Fi e Ethernet) para bloqueio imediato.

## O que foi feito

- **Refatoração Clean Architecture do DNS Sinkhole (`internal/domain/dns`)**:
  - Migração e reorganização dos use cases e handlers de `internal/infrastructure/dns` para a camada de domínio `internal/domain/dns`.
  - Definição de ports/interfaces desacopladas (`Controller`, `AdapterConfigurator`, `Persister`, `FirewallEnforcer`).
  - Use cases (`StartHandler`, `StopHandler`, `StatusHandler`, `SetUpstreamHandler`) com orquestração limpa, rollback atômico e injeção de dependências.
  - Testes unitários com mocks em memória cobrindo 100% dos fluxos.

- **Módulo de Configuração de DNS de Adaptadores (`internal/infrastructure/netdns`)**:
  - Implementação multiplataforma (`netdns_windows.go`, `netdns_linux.go`, `netdns_other.go`) com interface `Configurator`.
  - Detecção automática de adaptadores ativos (Wi-Fi, Ethernet) e apontamento do DNS primário para `127.0.0.1` / `::1`.
  - Restauração automática de adaptadores para DHCP no `dns-stop` e no encerramento ordenado do daemon.
  - Execução mockável via `execCommandContext` sem necessidade de privilégios de administrador nos testes unitários.

- **Integração no Daemon e Composition Root (`cmd/focusguard-daemon/main.go`)**:
  - Fiação dos handlers de `domain/dns` e do configurador `netdns`.
  - Conexão automática dos adaptadores no boot quando `DNSEnabled() == true` e restauração no shutdown.

- **Exclusões Automáticas do Windows Defender no Instalador MSI e no Doctor**:
  - `scripts/msi/wix.json` e `scripts/msi/wix-server.json`: adicionados Custom Actions deferred (`Add-MpPreference` / `Remove-MpPreference`) para que a instalação via `.msi` (executada com privilégio elevado `LocalSystem`) configure automaticamente as pastas e processos do FocusGuard na lista de exclusões do Windows Defender, e remova na desinstalação.
  - `scripts/install-daemon.ps1`: adicionadas chamadas a `Add-MpPreference` e `Remove-MpPreference` com preservação do UTF-8 BOM.
  - `cmd/focusguard/doctor.go` e `doctor_windows.go`: adicionada checagem diagnóstica `checkDefender` para alertar o usuário e sugerir o comando de correção se o FocusGuard não estiver excluído no Defender.

## Decisões importantes

- **Isolamento de Domínio e Infraestrutura**: `internal/domain/dns` não depende de implementações concretas do sistema operacional nem do protocolo DNS raw, dependendo apenas de interfaces (DIP).
- **Restauração garantida de DNS**: O daemon restaura os adaptadores para DHCP no shutdown ou caso ocorra erro ao persistir o estado no boot/start.
