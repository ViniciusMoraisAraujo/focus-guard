## Decisões importantes

- **VM Ubuntu com desktop é necessária** — WSL2 headless (usado nas Etapas
  2–6) não tem sessão gráfica; as Etapas 7–10 exigem GUI (tray na bandeja,
  navegador para CA/interceptor, notificações, web UI).
- **VirtualBox gratuito é suficiente** — não precisa de cloud VM; 4GB RAM,
  40GB disk, 2 cores é suficiente para compilar e testar.
- **Cross-compile no Windows é viável** — `GOOS=linux go build` funciona
  para testar compilação, mas binários nativos (tray com CGO) precisam da VM.
