## Decisões importantes

- **TTL do sinkhole mantido em 60s** (a Task pedia 10s) — decisão do
  usuário, alinhada ao spec (desbloqueio propaga em ≤1min, menos carga).
- **`IPV6_V6ONLY=1` no wildcard v6** — o default dual-stack do Go faria o
  segundo bind falhar com EADDRINUSE no Linux.
- **Regras inbound mantidas no `dns-stop`** — remover derrubaria o DNS de
  dispositivo que ainda aponta para a máquina (pior que regra inerte).
- **Interface `Enforcer` intocada** — capacidades novas via type-assert de
  interface local no daemon (~15 fakes de teste intactos).
- **Bypass IPv6 (`fe80::1`)** é config de roteador (RDNSS/DHCPv6), não de
  código — mitigação = listener v6 + docs/manual orientando desligar o
  anúncio de DNS IPv6 do roteador.
- **Hook mira os PADRÕES do footer, não a palavra solta** — a 1ª versão
  rejeitava qualquer "Codebuff" e barrou o próprio commit que documentava a
  regra; os padrões foram ancorados ao início da linha (o footer real sempre
  começa a linha), então prosa citando o padrão passa.
